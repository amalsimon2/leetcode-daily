# Altitude Gain Sequence

**Day:** 1

**Difficulty:** Easy

**Category:** Arrays

## Problem

You are given an array of integers representing the net altitude change between consecutive checkpoints of a journey. If the journey starts at an altitude of 0, find and return the maximum altitude reached at any point during the journey.

## Examples

### Input

[-5, 1, 5, 0, -7]

### Output

1

### Explanation

Altitudes are [0, -5, -4, 1, 1, -6]. The maximum altitude is 1.

### Input

[4, -3, 2, -2]

### Output

4

### Explanation

Altitudes are [0, 4, 1, 3, 1]. The maximum altitude is 4.

## Constraints

- 1 <= nums.length <= 1000
- -1000 <= nums[i] <= 1000


## Complexity

**Time Complexity:** O(n)

**Space Complexity:** O(1)
